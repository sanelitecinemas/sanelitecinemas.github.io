# Sanelite Cinemas ROI Module

Open `index.html` in any modern browser. This standalone interface was built from `ROI_final copy.xlsx` and uses the workbook’s base assumptions:

- 210 seats, 18 weekday days / 12 weekend days
- 3 weekday shows / 4 weekend shows
- 35% weekday occupancy, 45% weekend occupancy
- ₹200 weekday tickets, ₹250 weekend tickets, ₹80 F&B spend per booking
- 18% ticket GST (inclusive calculation), ₹25 show tax, 5% F&B GST
- 25% investor share and an 8% annual growth projection

All assumptions are editable in the dashboard; results update in real time. The "Export summary" button directly generates and downloads a formatted, executive-grade PDF summary for investors. No build step or external dependency is required.
